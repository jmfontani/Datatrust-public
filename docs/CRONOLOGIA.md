historial de desarrollo. Esta página conserva el calendario real, con las fechas de cierre de cada
bloque de trabajo (último commit que toca cada directorio en el repositorio de trabajo del equipo).

| Idear y prototipar | Ideación, ideas descartadas, prototipo Streamlit (POC) | 2026-10-01 |
| Sprint 1 · Ingesta | Descarga y verificación de los ~87,7 k datasets del catálogo, metadatos, manifiesto | 2026-10-01 |
| Sprint 2 · Embeddings | Embeddings multilingües e índices invertidos por tema, editor e idioma | 2026-10-01 |
| Sprint 3 · Búsqueda y UI | Motor híbrido (semántica + léxica), API de búsqueda, primeras interfaces | 2026-10-01 |
| Nivel 4 · Evaluación | Batería de evaluación y métricas iniciales | 2026-06-03 |
| Sprint 5 · Integración | Despliegue contenerizado (PostgreSQL + pgvector, API, frontend) y documentación de operación | 2026-10-26 |
